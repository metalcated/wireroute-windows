# WireRoute 1.1.2 (unsigned preview)

> [!WARNING]
> These Windows installers and portable archives are unsigned. Windows cannot yet verify WireRoute as the publisher. Verify your download against the attached SHA-256 manifest. Publicly trusted code signing is not currently configured; Microsoft Store registration is separate from this GitHub release.

## What's new

- **Automatic profiles:** choose a default VPN and separate actions for Wi-Fi, cellular, and Ethernet networks.
- **Named Wi-Fi rules:** keep automatically connected VPNs off on trusted Wi-Fi names, or assign a particular profile to a named network.
- **Integrated On-Demand controls:** open Automatic profiles from the Profiles sidebar, a profile's On-Demand action, or Settings. When enabled, it replaces single-profile On-Demand while preserving the saved rules in a paused state.
- **Editor navigation:** open the network settings without losing unsaved profile edits. Save and Cancel return to the surrounding editor.
- **Theme-aware controls:** the dialogs use the existing Blue Nordic and System themes, with a concise Automatic profiles button.

## Connection behavior

Automatic switching is off by default. It only switches connections started automatically by the current WireRoute session; it does not take over manually connected or pre-existing VPNs. Manual control pauses switching until the physical network changes or rules are saved. Turning automatic mode off leaves the current VPN connected.

Switching briefly disconnects the VPN and is **not a kill switch**. Rules run while WireRoute is open in the signed-in user's tray, and Windows may request administrator approval for tunnel start/stop operations. Named Wi-Fi rules hold the current connection when the network name cannot be read. See [Automatic profiles](https://github.com/metalcated/wireroute-windows/blob/v1.1.2/docs/AUTOMATIC_PROFILES.md) for setup and limitations.
