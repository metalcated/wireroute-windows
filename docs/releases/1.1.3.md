# WireRoute 1.1.3 (unsigned preview)

> [!WARNING]
> These Windows installers and portable archives are unsigned. Windows cannot yet verify WireRoute as the publisher. Verify your download against the attached SHA-256 manifest. Publicly trusted code signing is not currently configured; Microsoft Store registration is separate from this GitHub release.

## What's changed

- Removed the redundant **Automatic profiles** button above the sidebar profile list, leaving more room for saved profiles.
- Automatic profiles remains available through each saved profile's **On-Demand** action and **Settings → Automatic profiles**. Its rules and VPN behavior are unchanged.
- Updated the navigation documentation to match.

This is a small interface refinement to 1.1.2. It retains automatic profile switching, named Wi-Fi rules, and the existing Blue Nordic and System themes. See [Automatic profiles](https://github.com/metalcated/wireroute-windows/blob/v1.1.3/docs/AUTOMATIC_PROFILES.md) for setup and limitations.

## Downloads

Choose the architecture that matches your PC: **x64** or **ARM64**.

- `.msi`: Windows installer.
- `.zip`: complete portable application folder; extract the entire archive before running `WireRoute.exe`.
- `WireRoute-1.1.3-SHA256SUMS.txt`: checksums for all four downloads.

Version 1.1.3 supersedes 1.1.2. Earlier releases remain unchanged and available. This is a GitHub preview release, not a Microsoft Store submission.
